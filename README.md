# 📖 Fake Store

**Final Year Project**
is the backend of my master's project that helps archiving and notifying administration hierarchy on the operational interruption events that have occured :

- <b>All SECURED CRUD operations for all the models:</b>
  All models of the backend are provided with CRUD operations APIs with authentication and permission.
  APIs for showing statistics,by date range , or by month yearly.
  
# 🛠Built With

## Technologies

This project was created with following technologies:

- [Django Rest Framework]([https://github.com/hananeoba/fakestore/blob/dev/ReactNative/fakeStore/README.md](https://www.django-rest-framework.org/))
- Next JS](https://github.com/hananeoba/fakestore/blob/dev/NextJs/README.md)
- [FakeStoreAPI](https://fakestoreapi.com/)

## Key Features

- **All Crud operations are provided **
- ** Security with permission and authorization for all APIs**
- **User JWT Authentication and Authorization**

## 💻 Getting Started

To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:

- Installation of Python3
- Installation of Rest Framework
- Installation of cross
- A postman for checking and sending requests
- Internet connection
- A code editor like Visual Studio Code

### Setup

Clone this repository to your desired folder:

```sh
  cd my-folder
  git clone https://github.com/hananeoba/fakestore.git

```

### Usage

To use this project

1. Install dependencies

   ```bash
  pip install requirements.txt
   ```

2. Start the app

   ```bash
    ./manage.py runserver <your.IP.Address.here:port>
   ```
